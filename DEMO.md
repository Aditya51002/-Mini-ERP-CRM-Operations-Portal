# Demo Accounts

These are seeded demo accounts on a non-production deployment, not real credentials.

```text
ADMIN: admin@erp.test / Password123!
SALES: sales@erp.test / Password123!
WAREHOUSE: warehouse@erp.test / Password123!
ACCOUNTS: accounts@erp.test / Password123!
```

Create the users with `npm run seed` in a local development environment. Never
reuse these accounts or their password on an internet-facing production system.
